# 第一次使用

[← 返回项目首页](../README.md)

**先体验演示，再接入真实账号。** 演示使用项目自写材料，能检查你的电脑是否能生成和打开学习页面，不需要平台账号、采集器或模型 API Key。

## 你需要准备什么

| 准备项 | 用途 |
| --- | --- |
| 一台电脑与浏览器 | 生成、保存和阅读学习页面 |
| Python 3.11 或更新版本 | 运行这个本地工具 |
| 能操作本地文件和终端的 AI 助手 | 整理真实资料、运行命令、解释错误 |
| 真实账号对应的采集能力 | 演示不需要；处理账号前再检查 |

这里的 **Agent** 指能读取文件、执行任务的 AI 助手。只有文字问答能力的网页聊天窗口，通常不能替你运行本地项目。

## 路线 A：交给 Agent

复制 [首页的开始任务](../README.md#开始使用)。让 Agent 获取仓库、检查 Python，并运行演示。遇到环境问题时，把完整报错留给它处理。

成功后，你应该看到默认 `concept` 演示：**理解比例尺 → 估算实际距离**。两步活动分别是解释比例尺、完成一次距离换算；概览会展示学习需求与能力覆盖。这个案例没有附加模板，需要体验模板时可运行下方的 `project` 案例，其中提供两份自写材料。

再告诉它：目标博主的链接、你想学会的具体事情、目前基础和可用时间。Agent 应先确认该平台能否采集；缺少工具时，不能把演示结果当作你的真实账号结果。

## 路线 B：自己运行演示

### 1. 获取项目

在 [仓库主页](https://github.com/cyberpinkman/creator-to-curriculum) 点击 **Code → Download ZIP**，解压到容易找到的位置。也可以使用首页中的 `git clone` 命令。

### 2. 打开终端，进入项目文件夹

macOS / Linux 在终端运行；Windows 使用 PowerShell。下面的 `<项目文件夹的完整路径>` 要换成你解压后实际的位置，保留引号：

```bash
cd "<项目文件夹的完整路径>"
```

这个文件夹中应该能看到 `README.md`、`pyproject.toml` 和 `creator_curriculum/`。

### 3. 检查 Python 并生成演示

**macOS / Linux：**

```bash
python3 --version
python3 -m creator_curriculum demo-index --out .learning/demo-index
```

**Windows：**

```powershell
py -3 --version
py -3 -m creator_curriculum demo-index --out .learning/demo-index
```

版本需要是 3.11 或更新。未安装时可从 [Python 官方下载页](https://www.python.org/downloads/) 获取，或把报错交给 Agent。演示无需先运行 `pip install`。

`demo-index` 默认使用 `concept`，也可以用 `--scenario` 选择其他合成案例：

| 参数值 | 演示重点 |
| --- | --- |
| `concept` | 理解比例尺，再完成一次距离换算 |
| `practice` | 在自写名单 CSV 上练习清理与核对 |
| `project` | 从信息稿到海报草稿；同一主题的不同活动及两份模板 |
| `comparison` | 比较相反观点，保留分歧与待补条件 |
| `lookup` | 查阅碎片技巧，展示基础与必需资料的缺口 |

例如生成项目制作案例：

```bash
python3 -m creator_curriculum demo-index --scenario project --out .learning/project-demo
```

Windows 将 `python3` 换成 `py -3`。各案例使用不同输出目录；启动下面的本机服务后，项目案例可从 [project-demo/index.html](http://127.0.0.1:8766/project-demo/index.html) 打开。所有案例都是仓库自写内容，准备条件提示用于验证流程，不代表实际学习效果。

### 4. 打开学习页面

成功时，终端会返回结果目录的绝对路径。为便于下次继续，在同一项目目录启动本机服务：

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory .learning
```

Windows 使用 `py -3 -m http.server 8766 --bind 127.0.0.1 --directory .learning`。保持终端运行，打开 [本机演示页面](http://127.0.0.1:8766/demo-index/index.html)。已有本项目的同一入口时可直接复用；若端口被其他服务占用，改用一个空闲端口并记住它，以后保持同一地址。

第一次走完这个小流程：

1. 在概览选择路径，点击「开始这一步」，查看目标、原视频入口和停止点；演示没有真实可播放的视频。
2. 写一条自己的笔记，确认页面显示已保存。四种学习状态由你分别填写，不会因打开页面自动完成。
3. 从目录临时查阅另一个主题，查看先修、证据和学习活动；在包含资料的案例中，还可打开相关模板。
4. 刷新或重新打开同一地址，回到概览点击「继续查看当前任务」，检查原活动步骤和笔记仍在。临时查阅不会替换学习任务。

用完后可在服务终端按 Ctrl+C 停止。下次进入项目目录，运行同一服务命令，再打开同一地址即可；不需要安装常驻服务。浏览器、协议、主机名或端口变化可能使用另一份存储，换入口前先在「我的学习记录」导出备份。直接打开 `index.html` 也能阅读，但不同浏览器对 `file://` 的记录支持不同。

演示可离线阅读。真实账号结果中的原视频、在线参考仍需要联网，并可能要求登录来源平台。

## 做完或卡住后，怎样获得反馈

在活动页的尝试区域写下实际产物、卡点和完成方式。自己的作答、协助完成的作答、参考答案与来源不明内容要分别说明。每次保存是一条新尝试，旧内容保留；不会因为保存或打开视频自动勾选掌握。

导出学习记录交给 Agent，或者直接在对话里提供自己的产物。Agent 按当前活动标准反馈，指出依据、还不知道什么和下一步怎么做，更新页面后让你刷新查看。页面本身不会自动评分。文件打不开或资料缺失会作为条件问题处理；没有产物时先补证据，不猜测成绩。

明确采用建议才调整当前位置；只查看建议或目标页面不会自动改学。完成一个比较表可以收束本次任务，但原资料的分歧仍保留；某次产物符合标准也不代表已掌握整个主题。

可先体验带合成反馈的演示：

```bash
python3 -m creator_curriculum demo-index --scenario concept --feedback --out .learning/feedback-demo
```

沿用前面的本机服务，打开 [反馈演示](http://127.0.0.1:8766/feedback-demo/index.html)。全部尝试均为测试样例，没有真实学习者数据；使用新的输出目录。

## 接入真实账号前，确认这几件事

| 来源 | 当前条件 | 如果暂时不具备 |
| --- | --- | --- |
| 抖音 | 需要已配置的 video-learning 服务；它不包含在本仓库内 | 先使用演示或你已有的字幕，不承诺只贴链接就能采集 |
| YouTube / B 站 | 需另装 yt-dlp，当前仅实验性获取作品清单 | 可先导入已有资料；批量字幕和转写还需外部工具 |
| 本地文件 | 提供带时间戳的 JSON / SRT / VTT，以及可确认的来源 | 没有时间戳的纯文本不能自动变成精确的视频定位 |

采集可能受平台、登录、地区或当前可见范围影响。让 Agent 报告**实际取得了什么、缺了什么**，不要只根据返回条数判断“全部采集完成”。详见 [采集适配](adapters.md)。

## 学习结果在哪里

Agent 会给你实际生成的目录，通常位于 `.learning/账号名/`：

| 文件 | 用来做什么 |
| --- | --- |
| `index.html` | 主要阅读入口：知识地图、原视频导航、建议和资料 |
| `knowledge-map.svg` | 可保存的知识地图 |
| `video-index.csv` | 用表格软件查看原视频索引 |
| `README.md` / `materials.md` | 文字版目录与资料清单 |
| `learning-design.json` / `learning-design.md` | 当前路径的准备条件、能力覆盖和待处理缺口；不表示已经掌握 |
| `materials/` | 实际取得的文件和记录模板；不同案例内容不同 |
| `usage/report.md` | 已导入账本的用量汇总；需 Agent 先记录并生成报告 |

保存或移动结果时，建议**保留整个文件夹**，否则 HTML 中关联的本地资料可能打不开。支持的文本资料可以在资料详情直接阅读，也能下载原文件；修改资料后请让 Agent 重新生成页面以更新预览。不要直接修改内部 JSON；把需要调整的学习目标或目录交给 Agent。

## 遇到问题时

| 现象 | 可以先检查什么 |
| --- | --- |
| `python3` / `py` 找不到 | Python 是否已安装，终端是否需要重新打开 |
| `No module named creator_curriculum` | 是否进入包含 `pyproject.toml` 的项目根目录 |
| 页面能打开，但没有真实视频链接 | 是否打开了标有「虚构演示」的页面 |
| 本机地址打不开 | 服务终端是否仍在运行，地址端口是否与启动命令一致 |
| 重开后看不到原记录 | 是否使用同一浏览器、协议、主机名和端口；先检查原入口或导出的备份 |
| 粘贴博主链接后无法继续 | 是否配置了该平台的采集器；保存它返回的具体错误 |
| 原视频需要登录或已不可见 | 到来源平台查看；这不意味着索引里的所有内容都已失效 |
| 资料只有入口，没有文件 | 查看状态：尚未取得、需要登录或付费的材料不会假装已下载 |

请把执行命令、完整报错和预期结果交给 Agent；向公开 Issue 反馈前，移除 cookie、密钥、私人路径和学习资料。

## 费用与学习效果

演示不调用模型。处理真实账号会使用你选择的 Agent、模型或外部服务，其额度和费用取决于各自配置。模型返回的实际 token、估算和未知用量应分别记录；项目开发会话不能当作某位博主的固定处理成本。[查看用量样例](usage.md)。

地图帮助你选择要学的内容，练习结果才反映是否掌握。学习顺序由 Agent 整理，转写与截图可能遗漏信息，遇到疑问请回到原作核对。
